# XiaomiParts for dada

This device-specific port is derived from the XiaomiParts implementations in:

- https://github.com/crdroidandroid/android_device_xiaomi_munch, commit
  `8261edd27aab2e1f0441fed3d49a3d49743915b2`, authored by Kydyr Olzhas
  `<kdiroljas@gmail.com>`.
- https://github.com/crdroidandroid/android_device_xiaomi_sm8250-common, commit
  `1dc6de5447e1992a3d6e31c2beee4156bc0ea77d`, authored by D3nesyan
  `<d3nesyan@jmu.edu.cn>`.

The copyright and license notices in the individual source files are retained.
The dada-specific changes replace hardware interfaces that are not available on
the device while preserving attribution to the original projects and authors.

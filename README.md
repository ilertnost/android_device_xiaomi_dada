# Xiaomi 15 (dada)

LineageOS device tree adapted for Android 17.

The device keeps the display, LTPO, auto-brightness, audio and vibrator fixes
on the device side and uses the complete Android 17 vendor drop, including its
stock MiuiCamera stack.
